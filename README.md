Hotel Listings Analysis in the Netherlands

Project Overview

This project explores hotel listings in the Netherlands, focusing on hotel ratings, reviews, room types, and locations.

The goal is to clean and analyze the dataset, identify patterns, explore relationships between variables, and gain insights into hotel listings.

Project Objectives

* Clean and preprocess the dataset.
* Handle missing values and duplicate records.
* Explore hotel ratings and review counts.
* Analyze hotel locations and room types.
* Identify outliers in the data.
* Apply feature engineering and feature selection techniques.
* Explore dimensionality reduction using PCA.
* Analyze frequently used words in hotel names.

Tools and Techniques

* Python
* Pandas
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Outlier Detection
* Feature Engineering
* Feature Selection
* Principal Component Analysis (PCA)
* Text Analysis

Key Findings

* The cleaned dataset contains 525 records and 9 columns.
* The average hotel rating is approximately 8.33.
* Double Room is the most frequent room type.
* Delfshaven has the highest average rating in the analyzed results, at approximately 9.10.
* 47 outliers were identified in the review count.
* The most frequent word in hotel names is “hotel”.

Important Data Limitation

The Hotel_Price column contains missing values for all 525 records. Therefore, this project focuses on hotel ratings, reviews, room types, and locations rather than actual price comparisons.
